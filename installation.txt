================================================================================
DRAGRUSH AI TiEE ARCHITECTURE: COREWEAVE IMMUTABLE DEPLOYMENT GUIDE
================================================================================

PREREQUISITES
-------------
1. A valid CoreWeave Cloud `kubeconfig`.
2. Docker installed locally.
3. Access to a Docker registry (e.g., Docker Hub or GitHub Container Registry).

STEP 1: BUILD AND PUSH IMMUTABLE IMAGES
---------------------------------------
Replace <YOUR_REGISTRY> with your actual Docker registry namespace (e.g., your username).

$ docker build -t <YOUR_REGISTRY>/tiee-gateway:latest -f Dockerfile.gateway .
$ docker push <YOUR_REGISTRY>/tiee-gateway:latest

$ docker build -t <YOUR_REGISTRY>/tiee-engine:latest -f Dockerfile.engine .
$ docker push <YOUR_REGISTRY>/tiee-engine:latest

STEP 2: UPDATE MANIFEST & APPLY
-------------------------------
1. Edit `coreweave.yaml` and replace `<YOUR_REGISTRY>` on lines 112 and 144 with your namespace.
2. Ensure you have the Prometheus configmap created:
   $ kubectl create configmap prom-config --from-file=prometheus.yml
3. Apply the infrastructure:
   $ kubectl apply -f coreweave.yaml

STEP 3: EXECUTE LOAD TEST
-------------------------
Get the external IPs:
$ kubectl get svc

Run k6 pointing at the Gateway's EXTERNAL-IP:
$ k6 run load-test.js
